关键数据流：作业上传 → AI 处理 → 教师确认
教师上传作业图片
  → API: POST /api/assignments/upload
  → 文件存入 MinIO，返回 file_url
  → 创建 submission 记录（status: pending）
  → 入队 BullMQ：ImageAnalysisJob { submissionId }
  → 立即响应教师：{ jobId, status: "processing" }

Worker 拾取任务（异步）
  → 下载图片，图像预处理
  → 调 GLM-5V：识别题目/答案/批阅痕迹
  → 调 DeepSeek：错因分析 + 知识点匹配
  → 写 grading_result / teacher_mark 表
  → 更新 submission.status = "pending_confirm"
  → SSE 推送进度给教师前端

教师审核确认
  → API: PATCH /api/assignments/:id/confirm
  → 触发 StudentMasteryUpdateJob
  → 更新 student_mastery 表
  → 生成作业报告
模型路由器设计（支持切换）

统一接口 AIProvider 封装：
 • analyzeImage(imageUrl, prompt) → 默认 GLM-5V，可配置换其他视觉模型
 • generateText(prompt, context) → 默认 DeepSeek，可配置换 Claude/GPT
 • generateEmbedding(text) → 用于 pgvector RAG 检索
系统设置页面可配置每个能力绑定的模型和 API Key
