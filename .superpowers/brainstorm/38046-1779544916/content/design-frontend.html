状态管理策略
服务端状态：SWR
useSWR('/api/students/[id]/mastery')
useSWR('/api/assignments/[id]/grading')
// 教师确认后 mutate() 触发重新拉取
// 乐观更新：先改本地再同步后端
AI 任务进度：SSE + useJobStream
// 上传后得到 jobId
const {progress, status} =
  useJobStream(jobId)
// 自动连接 /api/jobs/[id]/stream
// status: processing→done→error
// 完成后 SWR mutate 触发数据刷新
本地 UI 状态：React useState/useReducer
批阅确认页：每题的教师修改值（score, errorType, kpId）
出题页：生成参数表单状态
图片标注层：hover/selected 题目区域高亮
★ 核心组件：AnnotatedImageViewer
作业图片 + SVG 叠加层
• 每题 bbox 渲染为彩色矩形框
• 颜色：绿(✓) / 红(✗) / 橙(低置信) / 灰(待确认)
• hover 显示题号+识别结果 tooltip
• click 右侧面板跳到对应题目
• 支持图片缩放/平移（pinch-zoom）
• 批阅痕迹：教师手写圈画用虚线框标注
关键页面交互线框：作业批改确认页（双栏布局）
